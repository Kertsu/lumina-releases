# Lumina guide

## Set up a gathering

Open Lumina, connect your audience display, and rehearse the steps below.
The **operator window** contains your controls. An **operator workspace** keeps
its own Bible selection and presentation settings; its tab selects that context.
Each workspace can have an **audience window** for the content people will see.

1. Select an operator tab. Use **+** to create another workspace if needed.
2. Use a quick reference or search to find Bible content. The World English Bible
   is available offline after installation.
3. Use the verse preview to inspect a candidate privately before sending it.
4. Choose **Open Audience**. Move the audience window to the intended display
   and use the available window/fullscreen controls as needed.
5. Send the selected verse and confirm the audience window shows it correctly.
6. Use **Blank** when you need to hide the displayed content.

Always check the actual audience display, rather than relying only on the
operator preview. Display routing and fullscreen behavior vary by platform.

## Workspaces and history

Tabs switch between operator workspaces. A tab's context menu provides workspace
actions, including renaming. Verse history helps return to prior selections;
projection history records audience-confirmed projections where available.
An unconfirmed projection does not prove the audience saw the change.

Closing an audience window and deleting a workspace are different actions.
Check any destructive confirmation carefully.

## Bible library

Open the Lumina menu and choose **Bible library** to inspect installed
translations. To add another translation, follow [the Bible import guide](IMPORT.md).
It explains which files work, the review steps, and an optional prompt for matching
an existing database's structure to Lumina's format. You are responsible for the
rights to material you import and project. Lumina's app license does not grant
rights to third-party Bible texts.

Removing an edition can affect later access to its content.
Retained saved copies may preserve historical text and its translation label;
they do not turn a missing edition into a current installed translation.

## Appearance and controls

Open **Settings** from the Lumina menu for application options. Workspace
appearance controls affect audience presentation. Rehearse long verses and
different translations on the real display so size and contrast remain legible.

Choose **Keyboard shortcuts** from the Lumina menu to see the shortcuts in your
installed version. Single-key shortcuts pause while typing.

## Updates

When online, Lumina checks quietly for updates. A dot appears on the Lumina menu
only when an update is available. Open **Update available** to read its details.
**Later** keeps the update available; **Update and restart** authorizes download,
installation, and restart. A restart can close audience windows, including during
an active presentation.

## Report a problem

Use the [bug-report form](https://github.com/Kertsu/lumina-releases/issues/new/choose).
Include the app version from **About**, OS/version, CPU architecture, what you
expected, what happened, and repeatable steps. Mention whether an audience
window or second display was involved. Attach only redacted screenshots/logs.

Beta runtime compatibility can vary by setup. A report helps identify
configuration-specific issues.
