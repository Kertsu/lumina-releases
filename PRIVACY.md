# Privacy

Updated 2 November 2026.

Lumina stores the Bible library, operator workspaces, settings, and presentation
history on your computer. The app does not require an account. It does not send
that local content to a Lumina cloud service.

When online, the updater requests metadata and packages hosted through GitHub
Pages and GitHub Releases. Those services receive ordinary network request data,
such as your IP address. Their handling is governed by
[GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
Opening external links also connects to the destination site.

The download website self-hosts its fonts and walkthrough. It includes no
analytics script or advertising tracker. GitHub still operates the hosting and
may process visitor request data under its own policies.

Submitting a bug report is optional. GitHub Issues are public after launch.
Review screenshots and logs for private passages, file paths, and personal
information before posting. Do not upload your database to a public issue.

Local data backups and deletion are controlled by you. Uninstalling the app does
not necessarily delete its data. For questions, contact the maintainer through
the releases repository without posting sensitive information publicly.
